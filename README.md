\# Home SIEM Lab



This project is a home cybersecurity SIEM lab built using Wazuh, Sysmon, Ubuntu Server, and Windows endpoints.



The goal of this project is to practice:

\- Security monitoring

\- Log analysis

\- Threat detection

\- Safe attack simulation

\- SOC investigation workflows



The lab will include:

\- Wazuh SIEM server

\- Windows endpoints

\- Sysmon telemetry

\- MITRE ATT\&CK mapping

\- Atomic Red Team simulations
